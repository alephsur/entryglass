# Domain Layer

Contains pure entry and swap-leg normalization, Solana identity validation,
ambiguous-trade handling, immutable evidence/coverage state, strict pre-entry
windows, historical-context coverage, later-price observations, review-job state,
four versioned Smart Trader flow rules, and current preflight state. The pattern
engine is deterministic and descriptive; there is no scoring. Framework, HTTP, and
persistence concerns remain outside the domain package.
